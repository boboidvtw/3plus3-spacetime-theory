# Operational Clocks v0.7 — Relational-Time Null Test

> **Status:** standard quantum-clock toy model. This stage defines the null hypothesis that a future temporal-emergence model must outperform.

Executable notebook:

[`notebooks/operational_clocks_v0.7.ipynb`](../notebooks/operational_clocks_v0.7.ipynb)

## 1. Why v0.7 is different

v0.1–v0.6 developed increasingly precise notions of systemhood and dynamic identity.

None of those stages required a physical clock.

v0.7 introduces explicit clock observables. This is the first stage that directly tests the phrase

[
\text{“system }S_i\text{ has its own clock reading }\tau_i\text{.”}
]

The result is deliberately conservative: standard quantum mechanics already provides local operational clock readings.

Therefore local clocks alone are not new physics.

## 2. Two operational qubit clocks

For qubit (i), take

[
H_i=\frac{\omega_i}{2}\sigma_z.
]

Prepare a coherent state with nonzero transverse Bloch vector.

Measure

[
X_i(t)=\langle\sigma_x^{(i)}\rangle,
\qquad
Y_i(t)=\langle\sigma_y^{(i)}\rangle.
]

Define the measurable phase

[
\phi_i(t)
=
\operatorname{atan2}(Y_i(t),X_i(t)).
]

After phase unwrapping, a local clock reading may be defined as

[
\boxed{
\tau_i^{op}
=
\frac{\phi_i}{\omega_i}
}
]

when visibility is sufficient and the clock calibration is known.

This is an **operational clock**, not a new time coordinate.

## 3. Coupled clocks

The notebook uses

[
H(t)
=
\frac{\omega_A}{2}Z_A
+
\frac{\omega_B}{2}Z_B
+
g(t)Z_AZ_B.
]

The coupling (g(t)) turns on and later turns off, representing a simple interaction/merger/separation episode.

Even entirely within standard QM, the interaction can:

- alter local phase evolution;
- entangle the clocks;
- reduce local clock visibility;
- make instantaneous phase extraction less reliable.

Therefore

[
\frac{\dot\phi_A}{\dot\phi_B}
\neq
\frac{\omega_A}{\omega_B}
]

during interaction is **not** evidence for new temporal physics.

## 4. Relational clock observable

Define

[
R_{AB}^{op}
=
\frac{d\tau_A^{op}}{d\tau_B^{op}}.
]

Equivalently, before calibration factors are applied, one can inspect the phase-rate ratio

[
R_{AB}^{\phi}
=
\frac{\dot\phi_A}{\dot\phi_B}.
]

This is the first concrete implementation in the project of the earlier abstract quantity

[
R_{ij}=\frac{d\tau_i}{d\tau_j}.
]

## 5. Correct null hypothesis

A naive comparison would be

[
R_{AB}^{obs}
-
\frac{\omega_A}{\omega_B}.
]

That is wrong whenever the clocks interact.

The correct null prediction is

[
R_{AB}^{std}
=
R_{AB}[
H_{full},
\rho_0,
\mathcal E,
g_{\mu\nu},
\text{calibration}
],
]

where the baseline includes, as appropriate:

- the full interaction Hamiltonian;
- quantum state preparation;
- open-system/environmental effects;
- measurement back-action;
- relativistic proper-time effects;
- known systematic clock shifts.

The candidate new-physics residual is

[
\boxed{
\Delta R_{AB}
=
R_{AB}^{obs}
-
R_{AB}^{std}.
}
]

## 6. v0.7 null result

In the notebook, the “observation” and the standard prediction are generated by the same declared Hamiltonian.

Therefore

[
\boxed{
\Delta R_{AB}=0
}
]

up to numerical precision.

This is the desired result.

It proves that the analysis pipeline does not manufacture a temporal anomaly merely because a dynamical identity event or interaction episode occurred.

## 7. Visibility condition

The operational phase

[
\phi_i=\operatorname{atan2}(Y_i,X_i)
]

becomes unstable if

[
V_i
=
\sqrt{X_i^2+Y_i^2}
\rightarrow0.
]

Therefore a valid relational-clock experiment must impose a visibility criterion

[
V_i>V_{min}.
]

Clock-rate ratios obtained near vanishing visibility should be treated as undefined rather than as extreme temporal effects.

This is an important experimental guardrail.

## 8. Clock time versus physical time

v0.7 forces a useful distinction:

### Clock reading

[
\tau_i^{op}=f(Q_i)
]

constructed from a measurable degree of freedom.

### Proper time

[
\tau_i^{GR}
]

determined by spacetime geometry/worldline.

### Proposed emergent temporal degree of freedom

[
\tau_i^{new}
]

would have to possess nonredundant physical content beyond both the operational clock and GR proper time.

Thus

[
\boxed{
\text{different clocks}
\not\Rightarrow
\text{different fundamental times}.
}
]

## 9. Identity event does not reset a clock

If systems combine at (t=t_*), assigning

[
\tau_C(t_*)=0
]

would merely choose an origin.

It would not demonstrate creation of time.

A genuine temporal-emergence claim must concern the dynamics or relational observables, not the numerical zero point.

This eliminates another potential ambiguity from the original intuition.

## 10. Standard reparameterization test

Suppose every local reading satisfies

[
\tau_i=f_i(t)
]

for monotonic (f_i), with all observables completely reproduced by standard dynamics.

Then the local-time description is a useful relational-clock language but does not add a new physical degree of freedom.

The project therefore adopts the strict criterion:

[
\boxed{
\text{new temporal physics requires an observable not removable by reparameterization}.
}
]

## 11. Consistency of relational rates

If all clock readings are differentiable functions of a common parameter,

[
R_{ij}
=
\frac{d\tau_i}{d\tau_j},
]

then wherever defined,

[
\boxed{
R_{ij}R_{jk}=R_{ik}.
}
]

This transitivity relation becomes a powerful consistency test.

Any future phenomenological correction must either satisfy it or explicitly introduce a non-integrable/path-dependent temporal structure.

The latter would be a much stronger theory and would require independent justification.

## 13. A falsifiable phenomenological form

The next stage may introduce, **only as a test ansatz**,

[
\frac{d\tau_i}{dt}
=
\frac{d\tau_i^{std}}{dt}
\left[
1+
\epsilon F_i(
\mathbf I_i,
\dot{\mathbf I}_i,
\text{identity events}
)
\right].
]

Then

[
R_{ij}^{new}
=
R_{ij}^{std}
\frac{1+\epsilon F_i}
{1+\epsilon F_j}.
]

This is not derived and should never be presented as a law.

Its purpose would be to answer a concrete question:

> If temporal identity really affected clock evolution, what measurable residual pattern would distinguish it from ordinary interaction shifts?

## 14. v0.8 target

v0.8 should implement the phenomenological ansatz with a small dimensionless (\epsilon) and impose strict consistency conditions:

1. (\epsilon\to0) recovers standard QM + GR;
2. no effect from arbitrary relabeling;
3. no clock anomaly from merely choosing a different subsystem partition;
4. relational transitivity is preserved unless explicitly abandoned;
5. no superluminal signaling;
6. the correction is tied to an objective dynamical-identity quantity;
7. the signal must survive subtraction of ordinary interaction-induced clock shifts.

Then perform parameter scans to determine what a hypothetical

[
\Delta R_{ij}
]

would actually look like.

This will not prove the hypothesis, but it will convert “emergent time” into a quantitatively falsifiable proposal.
