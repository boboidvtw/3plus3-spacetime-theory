# Version 2 Research Checkpoint — v0.1 through v0.14

> **Checkpoint status:** speculative research program, paused after v0.14 for consolidation. This document records what has been built, what has been rejected or weakened, and what must be established before temporal phenomenology resumes.

## 1. Starting idea

Version 2 departed from the original fixed `(3+3)` spacetime picture.

Instead of assuming several universal timelike coordinates, it explored the hypothesis that objectively individuated physical systems may carry local temporal histories:

[
S_i \leftrightarrow \tau_i.
]

Nested systems could therefore support nested histories without requiring a global manifold with an ever-growing number of timelike metric directions.

The working picture became closer to

[
\mathcal U\sim(M^3,\mathcal G_{sys})
]

than to a literal (mathbb R^{3+N}) spacetime.

## 2. Conceptual correction: different rates are not different times

Examples such as blood turnover, hair growth, atomic evolution and astronomical dynamics motivated the project, but Version 2 explicitly rejects the inference

[
\text{different process rates}
\Rightarrow
\text{different physical time dimensions}.
]

Standard physics already allows

[
X_i=X_i(t),
\qquad
\dot X_i\neq\dot X_j.
]

A genuinely new temporal degree of freedom would require operational consequences that cannot be removed by reparameterization or reproduced by standard QM/QFT plus GR.

This distinction remains foundational.

## 3. Temporal emergence became dynamical individuation

The early verbal rule

> combination creates a new time

was replaced by the more symmetric idea

[
\boxed{
\text{dynamical individuation}
\leftrightarrow
\text{candidate local temporal identity}.
}
]

Composition and separation can both create new effective system identities.

No conservation law for the number of temporal identities is assumed.

Material identity, dynamical identity and temporal identity were explicitly separated.

## 4. v0.1 — mathematical null hypothesis

`docs/mathematical-foundation-v2.md` established the primary null:

if every proposed local time satisfies

[
\tau_i=f_i(t)
]

and all observables remain unchanged, then the additional times are redundant labels.

GR proper time remains the conservative baseline.

The relational observable was identified as

[
R_{ij}=\frac{d\tau_i}{d\tau_j}.
]

A genuine anomaly would require

[
\Delta R_{ij}
=
R_{ij}
-
R_{ij}^{(GR+standard)}
\neq0.
]

No such anomaly has been derived or observed.

## 5. v0.2–v0.3 — systemhood profile

The project confronted the arbitrary-subset problem:

why should a hydrogen atom, human, star or composite system receive a temporal identity while an arbitrary collection of particles should not?

A provisional systemhood profile was introduced:

[
\boxed{
\mathbf I=(B,C,A,P)
}
]

with:

- (B): binding/cohesion;
- (C): correlation/integration;
- (A): dynamical autonomy;
- (P): persistence/predictive closure.

The project deliberately avoided prematurely collapsing these into one scalar.

A key counterexample was the Bell pair:

[
C=1
]

can coexist with negligible continuing internal interaction.

Therefore

[
\boxed{
\text{correlation}\neq\text{autonomy}\neq\text{binding}\neq\text{persistence}.
}
]

## 6. v0.4 — numerical diagnostics

Finite-dimensional simulations verified that the diagnostics can evolve independently.

For (H=JX\otimes X), an initial product state can dynamically reach maximal normalized mutual information.

A Bell state under local phase-flip noise showed that correlation and fidelity decay differently.

A major correction was made:

[
\text{fidelity to initial microscopic state}
\neq
\text{persistence}.
]

Persistence must compare actual future evolution against the prediction of a declared effective model.

## 7. v0.5–v0.6 — dynamic system identity

Interaction-graph models showed that preferred effective boundaries can emerge without semantic labels.

A four-node model supported a strong ({0,1}|{2,3}) partition when internal links dominated boundary links.

Making the bridge time-dependent produced:

[
\text{two clusters}
\rightarrow
\text{merged network}
\rightarrow
\text{two clusters}.
]

This established an important null result:

[
\boxed{
\text{dynamic system identity can emerge entirely inside standard quantum mechanics}.
}
]

Therefore system formation alone is not evidence for emergent physical time.

The system network was renamed

[
\mathcal G_{sys}
]

rather than (mathcal G_T), because temporal dynamics had not been established.

## 8. v0.7 — operational clocks

The project then required a measurable clock before discussing new time.

For qubit clocks,

[
\phi_i
=
\operatorname{atan2}
(\langle\sigma_y\rangle,
 \langle\sigma_x\rangle)
]

provides an operational phase when visibility is sufficient.

The correct standard baseline includes the full interaction Hamiltonian.

Thus a clock-rate change during interaction is not automatically anomalous.

The residual is

[
\boxed{
\Delta R_{ij}
=
R_{ij}^{obs}
-
R_{ij}^{std}.
}
]

## 9. v0.8 — first falsifiable temporal ansatz

A deliberately hypothetical correction was introduced:

[
\frac{d\tau_i}{dt}
=
N_i^{std}
[1+\epsilon F_i].
]

Then

[
R_{ij}^{new}
=
R_{ij}^{std}
\frac{1+\epsilon F_i}
{1+\epsilon F_j}.
]

For small (epsilon),

[
\Delta R_{ij}
\approx
\epsilon R_{ij}^{std}(F_i-F_j).
]

This exposed an important property:

[
F_i=F_j
\Rightarrow
\Delta R_{ij}=0.
]

A universal common-mode rescaling is invisible to purely relational clock ratios.

No evidence for nonzero (epsilon) was claimed.

## 10. v0.9–v0.10 — identifiability and cross-system prediction

Synthetic experiments demonstrated that precision alone cannot identify a temporal residual.

If

[
F\in\operatorname{span}\{G_1,G_2,\ldots\},
]

where (G_k) are ordinary clock-systematic templates, then the temporal coefficient is structurally non-identifiable.

No reduction in random noise solves exact degeneracy.

The project therefore moved to multi-experiment joint inference, forcing several synthetic identity transitions to share one temporal parameter while retaining experiment-specific nuisance terms.

Leave-one-experiment-out testing shifted the standard from curve fitting toward out-of-sample prediction.

## 11. v0.11 — functional-law compression

The project then stopped adding temporal freedom.

A major scale degeneracy was identified:

[
F\rightarrow cF,
\qquad
\epsilon\rightarrow\epsilon/c.
]

Therefore (epsilon) has no independent physical meaning until the normalization of (F) is fixed.

The directly identifiable quantities are product coefficients such as

[
\theta_k=\epsilon\alpha_k.
]

Model-selection tests also showed that (B,C,A,P) can become strongly collinear when generated by the same transition profile.

Hence

[
\boxed{
\text{predictive identifiability}
\neq
\text{mechanistic identifiability}.
}
]

## 12. v0.12 — basis separation

Temporal fitting was intentionally paused.

A heterogeneous counterexample suite showed that (B,C,A,P) can form a full-rank mathematical feature geometry.

This established only:

[
\boxed{
\text{four independent diagnostic directions are mathematically possible}.
}
]

It did not establish that nature provides four fundamental systemhood observables.

## 13. v0.13 — model-derived diagnostics

Hand-assigned systemhood scores were replaced by quantities computed from explicit toy models.

A strict rule was adopted:

[
\boxed{
\text{derive it, or mark it undefined}.
}
]

For example, free product pairs and interaction-off Bell pairs were not assigned invented binding scores when no separation-energy definition existed.

This suggested a more flexible interpretation:

[
\mathbf I_S
=
\{X_k(S):X_k\text{ is operationally defined for }S\},
]

rather than requiring every system to possess all four components.

## 14. v0.14 — intervention Jacobian

The latest stage moved from passive covariance to controlled manipulation.

For controls (mathbf u), define

[
M_{kj}
=
\frac{\partial I_k}
{\partial u_j}.
]

A formal four-control model can make (M) full rank.

But when the dimer binding proxy is tied physically to the same internal coupling,

[
E_{sep}=|J|,
]

only three independent controls remain and

[
\operatorname{rank}(M)\le3.
]

This produced the current methodological gate:

[
\boxed{
\text{Do not infer physical dimensionality from artificial control parameters introduced to manufacture rank.}
}
]

Diagnostic dimension and control dimension are now treated as distinct concepts.

## 15. Current status of the four diagnostics

### Correlation (C)

Currently the cleanest component in finite-dimensional quantum benchmarks.

It can be defined through normalized mutual information.

### Persistence (P)

Operational when an effective predictor, observables and prediction horizon are explicitly declared.

It is model-relative but meaningful.

### Autonomy (A)

Computable in the current models but still dependent on the chosen internal/external coupling proxy and reference normalization.

It needs a more invariant formulation.

### Binding (B)

Currently the least universal component.

Separation energy is natural for bound states but not obviously applicable to every effective system, open system or higher-level persistent organization.

Therefore (B) is presently treated as potentially domain-specific rather than mandatory.

## 16. What has **not** been established

As of v0.14, the project has **not** established:

1. that additional physical times exist;
2. that composites literally create new timelike dimensions;
3. that any clock anomaly exists;
4. that (epsilon\neq0);
5. that (F) has been derived from fundamental physics;
6. that (B,C,A,P) form a universal four-dimensional basis;
7. that the framework improves on GR, QM or QFT predictions;
8. a covariant Lagrangian/Hamiltonian for the temporal hypothesis;
9. a quantized theory;
10. a real experimental detection proposal with validated sensitivity.

These are open requirements, not details to be filled in later by assumption.

## 18. Current epistemic position

The strongest defensible statement is:

> Version 2 is a structured research framework for asking whether objectively individuated systems could support nonredundant relational temporal degrees of freedom. It currently provides systemhood diagnostics, operational-clock null models, falsifiability criteria and identifiability tests, but it has not established any new physical temporal degree of freedom.

The framework is therefore still a speculative hypothesis-generation program.

## 19. Deliberate pause

Temporal phenomenology is paused after v0.14.

The project should not resume fitting hypothetical temporal residuals until the systemhood foundation passes stronger operational tests.

This pause is a feature, not a failure: it prevents downstream statistical sophistication from hiding upstream definitional weakness.

## 20. Next research gate — v0.15

The next planned stage is a **multi-platform intervention atlas**.

Distinct physical model families should each provide only genuinely motivated controls:

[
M^{(r)}
=
\frac{\partial\mathbf I}
{\partial\mathbf u^{(r)}}.
]

Candidate families include:

- bound/interacting dimers;
- Bell/decoherence systems after interaction switch-off;
- driven open systems with predictive persistence;
- metastable effective states;
- classical/stochastic effective systems as a non-quantum comparison.

The union of their intervention directions should be tested for whether it spans the proposed systemhood space without artificial knobs.

If it does not, the basis should be reduced or redesigned before temporal dynamics resumes.
