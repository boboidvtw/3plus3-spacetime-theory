# Model-Derived Systemhood v0.13 — From Assigned Scores to Computed Diagnostics

> **Status:** finite-dimensional benchmark methodology. The quantities are computed from declared toy models, not measured from nature. No temporal residual is fitted in this stage.

Executable notebook:

[`notebooks/model_derived_systemhood_v0.13.ipynb`](../notebooks/model_derived_systemhood_v0.13.ipynb)

## 1. Research gate

v0.12 established only that a four-dimensional (B,C,A,P) geometry can be constructed if sufficiently diverse scores are assigned.

v0.13 removes that freedom.

The rule is:

[
\boxed{
\text{derive the diagnostic from the model, or mark it undefined.}
}
]

No missing systemhood component is filled by intuition merely to make a rectangular matrix.

## 2. Operational toy definitions

### Binding proxy

When a model has a declared separation-energy scale,

[
B
=
\frac{E_{sep}}
{E_{sep}+E_*}.
]

If no physically meaningful (E_{sep}) is defined for that benchmark,

[
B=\mathrm{undefined}.
]

### Correlation

For a two-qubit state,

[
C
=
\frac{
I(A:B)
}{2},
]

where

[
I(A:B)
=
S(\rho_A)+S(\rho_B)-S(\rho_{AB})
]

and entropy is measured in bits.

Thus

[
0\le C\le1.
]

### Autonomy

For the declared dimer/environment model,

[
A
=
\frac{|J|}
{|J|+|g|+J_0},
]

where (J) is internal coupling, (g) is external coupling and (J_0) is an explicit reference scale.

This remains a diagnostic, not a universal definition.

### Persistence

For the open-system benchmark, use predictive fidelity:

[
P
=
F(
\rho_{actual},
\rho_{predicted}
).
]

The prediction is generated by a declared effective model.

This follows the correction introduced in v0.4: persistence is not fidelity to the initial microscopic state.

## 3. Benchmark 1 — product free pair

Prepare

[
|+\rangle\otimes|+\rangle.
]

Then

[
C=0.
]

There is no continuing internal interaction in the declared model, so the coupling-based autonomy diagnostic gives its low/null value.

But there is no declared separation energy.

Therefore:

[
\boxed{
B=\mathrm{undefined}.
}
]

This is preferable to silently assigning (B=0), because “not bound according to a declared energy threshold” and “binding diagnostic not defined for this model” are logically different statements.

## 4. Benchmark 2 — Bell pair after interaction is off

Take

[
|\Phi^+\rangle
=
\frac{|00\rangle+|11\rangle}{\sqrt2}.
]

The normalized mutual information gives

[
C=1.
]

Now switch off the preparation interaction.

The pair retains high correlation but has no continuing internal coupling in the autonomy proxy.

Again, no separation-energy model is declared:

[
B=\mathrm{undefined}.
]

This remains a clean counterexample to

[
\text{correlation}
\Rightarrow
\text{binding/autonomous composite}.
]

## 5. Benchmark 3 — interacting dimer

Use an internal coupling (J) and generate an entangled state through standard unitary dynamics.

For this toy benchmark only, define

[
E_{sep}=|J|.
]

Then (B) is computable.

The same (J) also contributes to autonomy.

This immediately creates an important warning:

[
\boxed{
B\text{ and }A\text{ are not independently controlled in this benchmark family}.
}
]

Thus even model-derived features can remain structurally collinear.

## 6. Benchmark 4 — open dimer

Keep internal coupling (J) and introduce external coupling (g).

The autonomy diagnostic becomes

[
A(J,g)
=
\frac{|J|}
{|J|+|g|+J_0}.
]

The state also experiences a phase-flip channel,

[
\rho'
=
(1-p)\rho
+
p
(Z\otimes I)\rho(Z\otimes I).
]

This changes correlation and reduces predictive fidelity if the effective predictor neglects the channel.

Therefore the open-dimer family begins to separate:

[
C,quad A,quad P.
]

However, (g) and (p) are still chosen together in the current benchmark sequence, so full mechanistic independence is not yet established.

## 7. Missing-data principle

Let

[
Z_{phys}
]

contain the model-derived features.

Some entries are NaN/undefined.

v0.13 does **not**:

- replace them with zero;
- replace them with a mean;
- fit an imputation model;
- assign them by physical intuition.

Rank and singular-value calculations requiring all four coordinates are performed only on complete rows.

Lower-dimensional subspaces such as

[
(C,A,P)
]

can use additional incomplete rows when those components are well-defined.

## 8. Why undefined is scientifically useful

An undefined entry identifies a weakness in the proposed universal coordinate system.

If (B) cannot be naturally defined for broad classes of physical systems, there are at least three possibilities:

1. (B) is domain-specific rather than universal;
2. the definition of (B) must be generalized;
3. systemhood should not require a (B) coordinate for every system.

The correct response is not automatic imputation.

## 9. Complete-row geometry

The complete rows in v0.13 come mainly from interacting/open dimers.

The feature matrix can be analyzed through

[
Z_c
=
Z-\langle Z\rangle,
]

followed by singular-value decomposition.

But interpretation must remain conservative because the benchmark family shares common control parameters.

In particular:

- (B) depends on (J);
- (A) depends on (J) and (g);
- (C) depends on the state generated using (J);
- (P) depends on the chosen open-system channel.

Therefore a formal full rank, if obtained, would not yet establish broad physical independence.

## 10. Available-subspace analysis

Rows with undefined (B) still provide valid information about

[
(C,A),
quad
(C,P),
quad
(A,P),
quad
(C,A,P).
]

v0.13 explicitly analyzes these available subspaces rather than discarding all incomplete benchmarks.

This is a more realistic strategy for future heterogeneous physical systems.

## 11. Definition sensitivity

The autonomy proxy contains

[
J_0.
]

Changing (J_0) changes the numerical values of (A).

The notebook scans (J_0) to make this dependence visible.

Thus:

[
\boxed{
\text{computed}
\neq
\text{definition-independent}.
}
]

A quantity can be derived from a model yet still depend on a conventional normalization or diagnostic choice.

Future theory must distinguish:

- model-computed values;
- operationally measurable values;
- convention-dependent normalized scores;
- invariant physical quantities.

## 12. Main v0.13 result

The strongest result is methodological:

[
\boxed{
\text{a no-imputation, model-derived systemhood benchmark pipeline now exists}.
}
]

It immediately reveals two limitations that hand-assigned v0.12 scores could hide:

1. some coordinates are not naturally defined for every system;
2. several coordinates can share the same microscopic control parameter.

Therefore the four-dimensional basis has **not** yet passed physical validation.

## 13. Implication for the meaning of systemhood

The current evidence favors treating

[
\mathbf I=(B,C,A,P)
]

as a **diagnostic profile with optional/domain-dependent components**, rather than as a four-component fundamental state vector that every physical system must possess.

A more flexible notation is

[
\mathbf I_S
=
\{X_k(S):X_k\text{ operationally defined for }S\}.
]

This avoids forcing inappropriate coordinates onto systems.

## 14. Temporal hypothesis remains paused

No new (\Delta R) fit is performed in v0.13.

That pause remains scientifically necessary.

Until the systemhood inputs have robust operational definitions, fitting a temporal response to them would confuse uncertainty in the independent variables with evidence about the temporal law.

## 15. Next bottleneck

The largest problem is now **controlled independence**.

The benchmark suite needs experiments/models where one diagnostic can change while the others remain approximately fixed.

For example:

[
g\text{ varies while }J\text{ is fixed}
]

primarily probes autonomy.

Changing a dephasing probability while keeping Hamiltonian couplings fixed can probe correlation/persistence.

Changing a binding-energy parameter while compensating dynamics to keep other observables comparable can probe (B).

This is closer to causal intervention than passive correlation analysis.

## 16. v0.14 target — intervention matrix

The next stage should construct explicit interventions

[
do(J),\quad do(g),\quad do(p),\quad do(E_{sep}),\ldots
]

and measure their effects on the diagnostic vector:

[
M_{kj}
=
\frac{\partial I_k}
{\partial u_j},
]

where

[
\mathbf I=(B,C,A,P)
]

and (u_j) are independently controlled model parameters.

The key object becomes the Jacobian/intervention matrix

[
\boxed{
M=
\frac{\partial(B,C,A,P)}
{\partial(u_1,u_2,u_3,u_4,\ldots)}.
}
]

Then ask:

- what is (operatorname{rank}(M))?
- which diagnostics respond to the same controls?
- can a near-diagonal set of interventions be designed?
- which definitions remain convention-sensitive?

This is stronger than examining covariance in naturally co-varying trajectories.

The v0.14 gate is:

[
\boxed{
\text{Can }B,C,A,P\text{ be independently manipulated, not merely independently imagined?}
}
]

Only after that should temporal phenomenology resume.
